🦸‍♂️ Classificador de Nível de HeróiEste é um projeto prático desenvolvido para consolidar conhecimentos fundamentais de lógica de programação, utilizando variáveis, operadores, estruturas de repetição e condicionais.

📋 ObjetivoO sistema recebe o nome e a quantidade de experiência (XP) de um herói e, através de uma estrutura de decisão, determina em qual nível o herói se encontra.

Níveis de Classificação:
XPNívelMenor que 1.000 Ferro
Entre 1.001 e 2.000 Bronze
Entre 2.001 e 5.000 Prata
Entre 5.001 e 7.000 Ouro
Entre 7.001 e 8.000 Platina
Entre 8.001 e 9.000 Ascendente
Entre 9.001 e 10.000 Imortal
Maior ou igual a 10.001 Radiante
